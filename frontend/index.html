Справка MomentCut

🚀 Быстрый старт
  1. Загрузите видео — кнопкой «Загрузить видео», перетащив файлы в окно, или полем «С диска» (по пути, без копирования).
  2. Начнётся автоматический анализ (по умолчанию «Сигналы»). Прогресс виден в панели анализа.
  3. Откройте найденные моменты на таймлайне — клик по сегменту воспроизводит его в плеере.
  4. Включите нужные моменты в правой панели «Монтаж» и нажмите «✂️ Смонтировать».
  5. Скачайте готовый ролик кнопкой «⬇ Скачать видео».
📥 Загрузка, импорт и библиотека
  • Поддерживаются форматы: MP4, MOV, MKV, AVI, WebM, M4V, TS, FLV, WMV, MPG, MPEG, 3GP.
  • Импорт «с диска» — впишите путь к файлу и нажмите «📂 С диска»: видео не копируется, читается прямо по пути (бейдж «с диска»). При удалении такой записи исходник на диске сохраняется.
  • Загруженные видео, их анализ и распознанная речь сохраняются в кеше (data/cache/) и восстанавливаются после перезапуска сервера.
  • Кнопка «🧹 Очистить» убирает из библиотеки все видео: загруженные — вместе с файлами, «с диска» — только записи.
  • Кнопка «⌫» у видео в списке очищает его найденные моменты.
🧠 Анализ моментов (сигналы)

Ищет интересные моменты по трём сигналам:

  • 🔊 аудиоэнергия — крики, аплодисменты, музыкальные всплески;
  • 🎞️ смена сцен — нарезка и контрастные переходы;
  • 🏃 движение — активные/динамичные сцены.

Движок: Авто / GPU (NVDEC) / CPU — результаты одинаковые, на GPU анализ быстрее. Строгость отбора задаёт порог: выше — меньше, но «интереснее» моментов. Кнопка «↻ Пересчитать» запускает анализ заново.

🤖 ИИ-анализ

В панели анализа выберите Метод: ИИ — моменты ищет внешняя модель через OpenAI-совместимый API (OpenAI, OpenRouter, Ollama, LM Studio…).

  • Endpoint — адрес API (базовый; /chat/completions добавится автоматически), API-ключ и модель.
  • Что отправляем: кадры (каждый N-й), кадры + распознанная речь, или только речь.
  • Секунд за раз — видео обрабатывается по фрагментам, чтобы не переполнять контекст модели.
  • Системный промпт (дополнение) — сюда впишите, какие моменты считать интересными (базовые правила уже встроены).
  • Сколько моментов — ограничение числа итоговых моментов (0 = без лимита).
  • Поддерживается пауза/продолжение/стоп — прогресс сохраняется и после перезапуска.
  • Если сигнальный анализ уже есть, ИИ-моменты дополняют его. Фильтры «🔵 Алгоритм» / «🟣 ИИ» включают/выключают источники.
✏️ Таймлайн и редактирование
  • Зум: ползунок «Масштаб» (до ×40) и колёсико мыши над таймлайном (центрируется под курсором); «⤢» — показать весь ролик.
  • Границы сегментов можно двигать и растягивать прямо на таймлайне; время редактируется и в списке.
  • Галочки в списке найденных и в очереди монтажа включают/выключают момент без удаления.
  • «+ Кадр» добавляет момент вокруг текущей позиции плеера; «Очистить» убирает все моменты.
  • «⬇» у сегмента скачивает его отдельным файлом с текущими настройками экспорта.
  • Окно плеера растягивается за нижнюю ручку; скорость воспроизведения — 0.3×–4×.
🗣 Распознавание речи и поиск

Кнопка «🎙 Распознать речь» в панели «Поиск по словам»:

  • Локально — faster-whisper на вашем ПК (модели tiny…large-v3; при смене модели предыдущая выгружается). При наличии NVIDIA GPU речь распознаётся на видеокарте.
  • Внешний API — свой OpenAI-совместимый endpoint /audio/transcriptions, ключ и модель (настройки хранятся в браузере).
  • После распознавания слова появляются метками на таймлайне (наведение — слово и время, клик — перемотка), а в панели — поиск по словам и список всех слов.
  • Найденный фрагмент добавляется в монтаж кнопкой «＋».
  • Чекбокс «Субтитры при просмотре» показывает распознанную речь поверх видео в плеере.
🎭 Разделение по голосам (диаризация)
  • Включите «🎭 Разделять по голосам» перед распознаванием — реплики разных говорящих получат метки «Спикер 1…», цвета на таймлайне и префиксы в субтитрах.
  • Требуется токен Hugging Face (поле рядом; хранится только в браузере) и pyannote.audio (есть в requirements.txt).
  • Первый запуск скачивает закрытые модели с Hugging Face — нужно принять условия (см. README, шаг 5).
  • При наличии NVIDIA GPU диаризация ускоряется CUDA-сборкой torch (см. README).
✂️ Монтаж и экспорт
  • Разрешение: авто (максимальное) или фиксированное от 480p до 4K.
  • Движок: Гибрид (авто) / CPU / NVIDIA (NVENC) / AMD (AMF) / Intel (QSV). Если аппаратный кодер недоступен — автоматический фолбэк на CPU.
  • Формат: MP4 (H.264), MP4 (HEVC), WebM (VP9), MKV. Качество — CRF: ниже = лучше и тяжелее.
  • Переход между моментами: без перехода, кроссфейд, через чёрный/белый, растворение, шторка влево, сдвиг вправо или плашка-маркер (цветная вставка — удобно вырезать моменты в другом редакторе). Длительность — 0.3–3 с.
  • Субтитры (речь) — вшивают распознанную речь прямо в кадр (кириллица поддерживается). Требуется предварительное распознавание.
💾 Проекты
  • Кнопка «💾» в верхней панели сохраняет проект в JSON (видео, моменты, распознанную речь), «📂» — загружает его.
  • Проект ссылается на файлы в data/uploads/ — для переноса на другой компьютер перенесите и эти файлы (или добавьте видео «с диска» по пути).
🔒 Приватность

Сигнальный анализ и локальное распознавание речи выполняются на вашем компьютере; видео не отправляются никуда. В интернет уходят только:

  • запросы к указанным вами API (ИИ-анализ, внешнее распознавание);
  • скачивание моделей (whisper, диаризация) при первом запуске.

API-ключи и токен Hugging Face хранятся только в браузере (localStorage) и передаются на сервер лишь на время запроса — в кеш и проекты они не попадают.
